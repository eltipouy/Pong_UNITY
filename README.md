# 🎮 JUEGO | PONG | ING. EN VIDEOJUEGOS

¡Bienvenidos al proyecto de **Pong en Unity**!

Este proyecto fue desarrollado con fines educativos para estudiantes de **Ingeniería en Videojuegos**, como parte de la materia **Unity Aplicada en Videojuegos**.

El objetivo es que puedas explorar un videojuego 2D, analizar cómo está organizado y estudiar su implementación utilizando Unity y C#.

## 🎯 Objetivo del proyecto

Utilizar una versión funcional del clásico Pong como material de referencia para comprender los fundamentos de la programación y el desarrollo de videojuegos.

## 🛠️ Tecnologías utilizadas

- **Motor de desarrollo:** Unity 6
- **Versión de Unity:** 6000.6.4f1
- **Lenguaje de programación:** C#
- **Tipo de proyecto:** Videojuego 2D

## 📂 Archivos del proyecto

### Exportación para Unity

En este repositorio encontrarás el archivo exportado del proyecto, que puedes importar en Unity para explorar los elementos incluidos y estudiar cómo está construido el videojuego.

1. Descarga el archivo exportado desde este repositorio.
2. Abre Unity y el proyecto en el que quieras importar los recursos.
3. Importa el archivo exportado y revisa los elementos disponibles.
