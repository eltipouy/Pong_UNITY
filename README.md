# 🎮 JUEGO | PONG | ING. EN VIDEOJUEGOS

¡Bienvenidos al proyecto de **Pong en Unity**!

Este proyecto fue desarrollado con fines educativos para estudiantes de **Ingeniería en Videojuegos**, como parte de la materia **Unity Aplicada en Videojuegos**.

A través de este ejercicio, aprenderás los fundamentos del desarrollo de videojuegos utilizando Unity, mediante la creación de una versión del clásico Pong.

## 🎯 Objetivo del proyecto

Desarrollar un videojuego funcional que permita poner en práctica los conceptos y herramientas vistos durante las clases.

## 🛠️ Tecnologías utilizadas

- **Motor de desarrollo:** Unity
- **Lenguaje de programación:** C#
- **Tipo de proyecto:** Videojuego 2D

## 📥 Descargar el proyecto

1. Descarga o clona este repositorio.
2. Abre el proyecto desde Unity Hub.
3. Utiliza una versión compatible de Unity para abrirlo.
4. Explora las escenas, scripts y recursos incluidos.

## 🎓 Uso educativo

Este proyecto está destinado a fines educativos y forma parte de las actividades prácticas utilizadas en clase. Puedes descargarlo, explorarlo y utilizarlo como referencia para tu aprendizaje.
